# 🛠️ Technologies Used

ClassConnect is built using modern frontend and backend technologies to provide a smooth, secure, and real-time video conferencing experience.

## 🗄️ Database

- **MongoDB** — Stores application data, such as user accounts and meeting information.

## 🎨 Frontend

- **React.js** — Builds the interactive user interface.
- **Material UI (MUI)** — Provides reusable, modern UI components.
- **CSS** — Styles the application and makes it responsive.
- **Axios** — Sends HTTP requests between the frontend and backend.
- **WebRTC** — Enables real-time audio and video communication between users.

## ⚙️ Backend

- **Node.js** — Runs JavaScript on the server.
- **Express.js** — Handles API routes and server-side requests.
- **Socket.IO / WebSocket** — Enables real-time communication and signaling between users.
- **bcrypt** — Hashes passwords securely before storing them.
- **Crypto** — Provides cryptographic utilities for security-related operations.
